# Phase (b) — questions for the owner

*Only questions whose answer changes what gets built. Most important first. Everything else is decided in `design.md` under "Judgment calls".*

## 1. Where do you mark busy nights?
- **A. One line under the week's dinners ("Busy nights: Tue and Thu · Change") opening one sheet. Each night gets Not busy / This week / Every week.** *(recommended)*
- B. Every-week busy nights live in Household settings; this-week ones are marked on the week.
- C. A "busy" switch inside each night, set one night at a time.

**Recommended: A.** One place for both kinds, one tap per night, and you can see the whole week's pattern at once. B splits one idea across two screens. C means opening seven things.

## 2. "Cook double" replaces the − / + leftovers buttons. OK to drop "just a bit extra"?
- **A. Yes. Leftovers are a full second dinner: Cook double, with a night or with "No set night" for lunches.** Extra servings you've already set stay as they are. *(recommended)*
- B. Keep both: Cook double, and the − / + buttons under it for a serving or two more.

**Recommended: A.** One control instead of two that overlap, and the phase overview already planned it this way. B costs about an hour and a busier sheet; say so if you use the + button today.

## 3. You take the leftovers night off the week. What happens to the cooking night?
- **A. It goes back to the usual amount.** The sheet says so before you tap. *(recommended)*
- B. It stays doubled (extra for lunches) until you change it.
- C. Ask each time.

**Recommended: A.** Taking leftovers off almost always means the plan changed, and a doubled dinner nobody will eat is wasted money. If you did want lunches, Cook double → No set night is two taps.

## 4. On a busy night, should the Favorites tab be filtered to quick dinners too?
- **A. Yes. One switch covers Search and Favorites, with "Show all" always one tap away.** *(recommended)*
- B. No. Only search results are filtered; Favorites always shows everything.

**Recommended: A.** Most dinners come from Favorites, so filtering only search would make busy nights do little. The catch: favorites saved before phase (a) have no time until it's filled in, so a few quick ones may sit behind "Show all" for a while.

## Decided without asking
- A night that's already planned can't be picked for leftovers.
- Leftovers stay in the same week, on a later night, at most four days on (your earlier answer plus the 3–4 day rule).
- Removing the cooking night removes its leftovers, and the sheet says so first.
- A recipe that doesn't say how long it takes is not quick.
- A slow dinner on a busy night is allowed and gets no warning.
- The "Quick dinners only" tick starts on each time and isn't remembered.
- "How was dinner?" is never asked about a leftovers night.
